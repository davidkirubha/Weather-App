# Weather App 🌦️

A simple and responsive Weather App built using HTML, CSS, and JavaScript. It allows users to search for a city and view its current weather information using the OpenWeather API.

## 🚀 Live Demo

[View Weather App](https://weather-app-kirubha-army.vercel.app/)

## ✨ Features

- Search weather by city name
- Display current temperature in Celsius
- Show weather description
- Fetch real-time weather data using OpenWeather API

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeather API

## 📌 How to Run Locally

1. Clone this repository:
   `git clone https://github.com/davidkirubha/Weather-App.git`
2. Open the project folder.
3. Configure your OpenWeather API key in the JavaScript file.
4. Open `index.html` in your browser.
